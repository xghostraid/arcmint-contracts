promptfun.fun in Claude

promptfun.fun is a remote MCP connector. Claude calls it to prepare blockchain actions, show you a plain-language preview, and return a receipt checked against the chain.

Sixty seconds to set up

Same three steps as adding any Claude custom connector. No promptfun.fun account.

  1. Copy the connector link

    https://promptfun.fun/mcp

    Same URL as on the home page. Authentication: No sign-in unless OAuth is required.

  2. Add it to Claude

    Open in Claude

    Or on claude.ai or in Claude Desktop: Customize → Connectors → + Add → Add custom connector. Name it promptfun.fun, paste the link, choose No sign-in if asked, then Continue and Add.

    Works on Claude Free (one custom connector), Pro, Max, Team and Enterprise. On Team and Enterprise, an Owner adds it for the organization first.

  3. Turn it on and ask

    In a chat, open + → Connectors and switch promptfun.fun on. Say what you want, for example “Launch a token called Moonbeam, ticker BEAM.” Claude shows the preview; you approve in your wallet (or in chat once sponsored launch ships); the receipt comes back in the same chat.

Launching a token

  1. Ask in plain language. Claude fills in name and ticker if you did not specify them.
  2. promptfun.fun builds the exact transaction and reads it back in the preview: network, fee payer and what gets created.
  3. You approve in your wallet today on Solana devnet. Sponsored launch with no wallet is Being built.
  4. After confirmation, Claude returns a receipt with explorer links and a ready-to-post message for X. Nothing is marked “done” until the chain confirms it.

What Claude can call

  • prepare_launch — read-only preview of a token launch.
  • confirm_launch — write action after you approve (card button in chat when available).
  • get_action_status — receipt for a confirmed action.
  • coin_status — live coin details from the public coins API (when indexed).
  • prepare_transfer, get_balance — send tokens or read balances with the same preview → approve → receipt flow.

Limits and networks

Solana devnet is in testing today with your own wallet. Mainnet, pump.fun and EVM chains are labelled on the Chains section of the home page. Global rate limits apply while the connector is in testing.

Troubleshooting

Claude says the connector is unavailable

Check that promptfun.fun is toggled on under + → Connectors and that the public link is live. If the service is paused, the home page says so.

I approved but nothing landed on chain

Ask Claude to check the action status. Failed or cancelled transactions are reported honestly; promptfun.fun never fakes success.

Where are my keys?

promptfun.fun never asks for a seed phrase. Your wallet signs when you use your own wallet. Sponsored launch will not require exporting keys either.
